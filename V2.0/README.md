LinkList.h实现了泛型单链表，泛型双链表
Stack.h实现了泛型栈(DeQueue)
Queue.h实现了泛型队列(EnQueue,DeQueue)
BTree.h实现了二叉树(BinaryTree),最优带权二叉树(HuffmanTree)
Search.h实现了二叉排序树，二叉搜索树，平衡二叉树，红黑树
Sort.h实现的泛型顺序表，泛型堆(需要用户自己设计cmp)
String.h实现了字符串的BF和KMP匹配算法
Graph.h实现了泛型图

项目缺点:
没有解决深拷贝和浅拷贝的问题
模版类的type无法是std::string等复杂类型
AVL和RBT部分的算法还未完成
ALGrph的部分还未完成
图的最小生成树算法(Kruskal,Prim)算法还未实现
