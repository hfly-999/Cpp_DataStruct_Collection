# V1.0 — 数据结构基础库

> 编写时间：2025-08-07　|　语言：C/C++　|　规模：20 个源文件

## 简介

这是三个版本里最早的一版，用 **C 风格（结构体 + 全局函数）** 手写的数据结构练习库。覆盖线性表、链表、栈、队列、串、树、图、查找、排序九大模块，并且大量实现了 408/王道考研的数据结构真题。

代码没有使用 STL 容器，所有结构都自己定义、自己管理内存；`Define.h` 统一了类型别名和常量，各模块按「一个结构一个 `.h` + `.cpp`」拆分。

## 文件结构

| 文件 | 模块 | 主要内容 |
| --- | --- | --- |
| `Define.h` | 公共头 | 类型别名（`ElemType = char`、`KeyType = int`）、`MAXSIZE` 等常量、常用头文件 |
| `SqList.h/.cpp` | 顺序表 | 初始化、插入、删除、按值查找，以及 408 顺序表真题 |
| `LinkList.h/.cpp` | 链表 | 单链表、双链表、循环双链表及链表真题 |
| `Stack.h/.cpp` | 栈 | 顺序栈、链栈，另有一个 `void*` 通用 `Stack` 类 |
| `Queue.h/.cpp` | 队列 | 顺序队列、带头结点的链队列 |
| `String.h/.cpp` | 串 | KMP 算法（当前为注释状态，见「已知问题」） |
| `Tree.h/.cpp` | 树 | 二叉树、线索二叉树、树/森林表示、哈夫曼树 |
| `Graph.h/.cpp` | 图 | 邻接矩阵/邻接表、DFS/BFS、最小生成树、最短路径、拓扑排序 |
| `Search.h/.cpp` | 查找 | 顺序/二分查找、二叉排序树、AVL、红黑树、B 树、哈希表 |
| `Sort.h/.cpp` | 排序 | 插入、希尔、冒泡、快速、堆、归并、桶、计数排序 |
| `main.cpp` | 入口 | 空 `main()`，仅包含头文件 |

## 功能特性

### 顺序表

- 基本操作：`InitSqList`、`SqListInsert`、`SqListDelElem`、`SqListLocateElem`、`PrintSqList`
- 408 真题：删除值为 `x` 的元素、删除 `s~t` 区间元素、有序表去重、有序表查找并插入/交换、合并两个顺序表、合并两个有序表、`(a1..am)` 与 `(b1..bn)` 整体互换、三个有序数组求交集、两个有序数组求中位数、求未出现的最小正整数

### 链表

- 单链表、双链表、循环双链表
- 基础：初始化、按位插入、打印
- 进阶：判断 B 是否为 A 的连续子链（BF/KMP 两种写法）、循环双链表对称判断、删除值为 `x` 的结点、删除最小值结点、就地逆置、删除 `s~t` 区间、找两链表首个公共结点、链表拆分、去重、两有序表求交集/合并、右移 `k` 位、判环并返回入环点、判断单链表是否对称

### 栈与队列

- 顺序栈：`Init`、`Push`、`Pop`、`Print`、`IsEmpty`、`SeqStackGetLength`、`ClearSeqStack`、`Destroy`
- 链栈：`Init`、`Push`、`Pop`、`Print`
- 顺序队列：`Init`、`Push`、`Pop`、`Print`、`GetSqQueueLength`、`GetHeadElem`
- 链队列：`Init`、`Push`、`Pop`、`Destroy`、`Print`、`EnQueue`、`DeQueue`
- 额外提供一个基于 `void*` 的通用 `Stack` 类，可存放任意指针

### 树

- 二叉树：递归/非递归先序、中序、后序、层次遍历
- 先序建树、复制、统计结点数、叶子数、树高（递归/非递归）、判断完全二叉树、统计度为 2 的结点、交换左右子树、判断相似、删除值为 `x` 的子树、查找祖先、最近公共祖先、从左到右连接叶子结点、计算带权路径长度（WPL）、满二叉树先序转后序、二叉树转中缀表达式
- 线索二叉树：中序线索化、线索遍历
- 树的表示：双亲表示法、孩子链表表示法、孩子兄弟表示法
- 哈夫曼树：根据词频构建、排序、后序遍历、编码打印（加密）、根据文本自动统计词频

### 图

- 邻接矩阵 `AMGraph`、邻接表 `ALGraph`、无向网构建、打印、顶点定位
- 求第一个邻接点 / 下一个邻接点
- 深度优先搜索、广度优先搜索
- 最小生成树：Prim、Kruskal
- 最短路径：Dijkstra、Floyd
- 拓扑排序、关键路径（标注待完成）、判边是否存在、邻接表转邻接矩阵、简单路径、DFS 拓扑排序、拓扑序列唯一性判断

### 查找

- 顺序查找、二分查找（非递归/递归）
- 二叉排序树：构建、插入、删除、中序查找/二分查找
- 平衡二叉树：遍历更新平衡因子
- 红黑树：插入、四种旋转（LL/LR/RR/RL）、变色、删除（标注待修正）
- n 阶 B 树：初始化、上溢/下溢判断、插入、删除、中序遍历
- 哈希表：开放地址法、拉链法，插入与查找
- 408 真题：判断二叉排序树、判断 AVL、从大到小输出不小于 `k` 的元素

### 排序

- 直接插入、折半插入、希尔、冒泡、快速、堆、归并、桶、计数排序
- 堆额外支持无序插入和有序插入

## 编译

原项目没有提交 Visual Studio 工程文件，可以自己新建空控制台项目，把全部 `.cpp` 加入，或用 g++ 编译：

```bash
g++ -std=c++14 *.cpp -o datastruct
```

> 依赖 `Windows.h`，`main.cpp` 目前是空入口，没有组织测试用例。

- **单文件体量大**：`Search.cpp` 约 26KB、`Tree.cpp` 约 17KB、`Graph.cpp` 约 15KB
